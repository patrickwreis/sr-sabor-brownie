Sr Sabor.Brownie Catalog

Catalog-only WordPress plugin. It adds an editable Brownies area to wp-admin and displays the products with WhatsApp order links. No cart or checkout is included.

Installation
1. Upload sr-sabor-brownie-catalog.zip under Plugins > Add New > Upload Plugin.
2. Activate Sr Sabor.Brownie Catalog.
3. Create a page named Cardapio and add the shortcode [srb_catalog].
4. Add or edit products under Brownies. Set the title, description, line, price, weight, and featured image.
5. Update the WhatsApp number under Brownies > WhatsApp.

The first activation adds 13 example products if the catalog is empty. Edit or delete them as needed.

For WordPress.com, use a paid plan that allows third-party plugin uploads. The plugin has not been tested against a live WordPress.com account from this workspace.
